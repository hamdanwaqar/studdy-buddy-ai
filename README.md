# 📚 Study-Buddy-Clone-Project (AI)

## 🧠 Project Overview

**Study Buddy Clone (AI)** is a collaborative study platform inspired by Study Buddy–style applications. It allows authenticated users to create discussion rooms, participate in conversations, and communicate through a real-time messaging system. The project focuses on community-based learning, interaction, and profile personalization.

---

## 🎯 Core Features

### 🔐 Authentication

* User registration and login
* Secure authentication for all actions
* Only authorized users can create rooms or send messages

---

### 🏠 Room Management

* Create new study rooms
* Join and participate in existing rooms
* Delete rooms created by the user
* View all rooms created by the logged-in user

---

### 💬 Messaging System

* Send messages within rooms
* Participate in active conversations
* Delete messages authored by the user
* View all messages created by the user on the profile page

---

### 👤 User Profile

* Update personal profile information
* View:

  * Rooms created by the user
  * Messages sent by the user
* Manage personal activity from a centralized profile page

---

### 🎨 Theme & UI

* Clean and user-friendly interface
* Consistent theme for better readability and engagement
* Designed for collaborative learning environments

---

## 🧑‍🤝‍🧑 User Permissions

* Every authenticated user can:

  * Create and delete rooms
  * Send and delete their own messages
  * Update their profile details
  * Participate in room discussions
